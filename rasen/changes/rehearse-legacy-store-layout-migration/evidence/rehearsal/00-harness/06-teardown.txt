### Teardown (tasks.md 2.7)

Unregistering happens ONLY inside the redirected per-stage homes, each of
which holds exactly one disposable copy (plus, for the enriched stage, the two
disposable member projects). The pre-flight runs FIRST in every home and
proves what that registry contains before anything is removed -- so an
unregister can only ever reach a path inside the temp root. No unregister
command was aimed at the real machine registry at any point in this change.
